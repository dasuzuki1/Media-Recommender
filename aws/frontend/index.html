Media Recommender

Personalized anime recommendations

Log in with AniList. The backend syncs your watch history into DynamoDB, and an hourly Lambda recomputes recommendations using a hybrid of content-based (genre cosine similarity) and item-item collaborative filtering. Reads are served straight from a precomputed table — sub-100 ms per query.

v2 — Serverless on AWS (Lambda · API Gateway · DynamoDB · EventBridge · CloudFront). v1 Flask MVP lives at src/frontend/website.py.
